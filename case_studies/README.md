# Unit 3: Applied Case Studies

Case studies synthesize the earlier units into decision-ready work. Each project should state the business question, document the data and assumptions, establish a baseline, evaluate results, analyze errors, make a recommendation, and name limitations.

## Projects

- [Traditional DS Case Study](traditional_ds_case_study/): Choose either customer churn or demand forecasting. Include feature work, validation, a justified tuning experiment, and a stakeholder recommendation.
- [Resume-Job Match RAG](resume_job_match_rag/): Apply the RAG and LLM-evaluation foundations to a grounded resume and job-description retrieval problem. Include a labeled evaluation set, limitations, privacy considerations, and architecture documentation.

The two projects are deliberately different: one demonstrates classical data-science judgment, and the other demonstrates modern AI-system evaluation.
