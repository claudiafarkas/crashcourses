# Topic: ML System Design

This topic is practice for turning an ambiguous request into a deployable, measurable machine-learning system. The point is to reason about decisions and tradeoffs, not just draw architecture diagrams.

## Notebook

- [ML System Design Exercises](ml_system_design_exercises.ipynb): Work through churn, fraud, forecasting, and RAG prompts. For each, define the target, prediction granularity, data sources, success and guardrail metrics, batch versus real-time inference, monitoring, drift response, retraining, and rollback.
