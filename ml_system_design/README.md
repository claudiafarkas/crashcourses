# Unit 4: ML System Design

This unit practices turning an ambiguous request into a deployable and measurable machine-learning system. The goal is to reason about decisions and tradeoffs, not just draw architecture diagrams.

## Notebook

- [ML System Design Exercises](ml_system_design_exercises.ipynb): Work through churn, fraud, forecasting, and RAG prompts. For each, define the target and unit of prediction, data sources, success and guardrail metrics, batch versus real-time inference, monitoring, drift response, retraining, and rollback.
