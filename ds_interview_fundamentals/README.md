# Topic: DS Interview Fundamentals

This is my hands-on practice area for common data-science interview topics. The notebooks pair short explanations with runnable exercises and clearly separated solutions.

## Notebooks

- [SQL for Data Science](sql_for_data_science.ipynb): Joins, CTEs, window functions, cohorts, funnels, and data-quality queries.
- [Statistics & Probability](statistics_probability.ipynb): Distributions, conditional probability, inference, confidence intervals, hypothesis tests, and common pitfalls.
- [A/B Testing & Experiment Design](ab_testing_experiment_design.ipynb): Metrics, randomization, power, effect size, significance, and experimental failure modes.
- [Time Series & Forecasting](time_series_forecasting.ipynb): Trend, seasonality, lags, chronological validation, baselines, and uncertainty.
- [Python Coding Patterns](python_coding_patterns.ipynb): Complexity, hash maps, sliding windows, intervals, stacks, queues, and binary search.
